# 生成画像を使ったTELEMOヒーローUI 10案

`index.html` は10案の比較ページです。各案を開くと、現在のヒーローの文言・ボタンに生成画像を組み合わせたUIを確認できます。既存LPへの反映は行っていません。

- 画像生成：組み込み image_gen。10案を別々のプロンプトで生成。
- 画像：`assets/` に10点のPNGを保存。元の生成画像を加工せず使用。
- プロンプトと生成元パス：`prompts.json`。
- ミニ社長：既存 `assets/concierge/president-cutout/poster.webp` をそのまま使用。各案で共通の固定位置（PCは右24px・下16px、SPは右14px・下12px）に表示。
- 写真、架空の社内風景、ロゴの造形、道具は生成イメージ。実際の職場・サービスのハードウェア・導入実績ではない。各UIと比較ページに注記。
- コピーとCTAは画像に焼き込まずHTMLで配置。ボタン文言・遷移先は現行ヒーローに合わせた。
- ブランド色はティール・濃紺・オレンジ・白を生成プロンプトとCSSで指定。画像の素材・陰影には濃淡がある。

## 検証

PC 1280×800とSP 390×844で全10案を撮影し、計20画面を目視。01・02の文字色、09・10の問い合わせリンクの背景を調整した。

`qa/layout.json`：20画面すべてで横はみ出し・画像読み込み失敗なし、見出しと主CTAは画面内。ミニ社長の位置は同一画面幅で全10案が一致。

`qa/detect.txt`：`npx impeccable detect heroes/generated-ui/` は終了コード0・指摘0。共有CSSは正規表現評価のみで一部ルール未適用という注意あり。包括的なアクセシビリティ合格の意味ではない。

`screenshots/`：各案のdesktop/mobile PNG、比較ページ、全案のコンタクトシート。
