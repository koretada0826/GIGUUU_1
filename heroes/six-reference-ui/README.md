ミニ社長とTELEMOの文字を主役にする方針を保ち、素材と構図を案ごとに変えた比較用UI。既存LPは変更していない。前の提案は `../monograph-ui/` と `../generated-ui/` に保持。

## 素材と内容

- 背景と文字造形は組み込みimage_genで8点を別々に生成。プロンプト・元画像の保存先は `prompts.json`。
- ミニ社長は既存 `assets/concierge/president-cutout/poster.webp` をそのままHTMLで重ねた。顔・服・ポーズを描き直していない。
- 社長の固定位置はPC右24px・下16px、SP右14px・下12px。表示サイズはPC200×300px、SP100×150px。
- コピーとCTA文言・リンクは現行ヒーローを使用。
- 参照元の画像・ロゴ・キャラクター・文言・実績は納品物に流用していない。
- 写真や造形は生成イメージであり、実際の職場・導入実績・商品を示さない。
- ブランドパレットは白・濃紺・ティール・オレンジ。画像内の素材や陰影には濃淡がある。
- UIの構図は左コピー、右コピー、上コピーの3系統で比較。スマートフォンでは読み順と文字の可読性を優先して縦に並べる。

## 検証結果

全8案をPC1280×800・SP390×844で撮影し、計16画面を目視確認。01のコピー領域、03・06・09のSP画像位置を調整して再撮影した。05・10削除後の8案でレイアウト検証を再実行した。

横はみ出し・画像欠落・主見出しと主CTAの画面外配置は0件。社長の画像ソースと固定位置は同じ画面幅で全案一致。`qa/layout.json` を参照。

`npx impeccable detect heroes/six-reference-ui/` は終了コード0・指摘0。単独CSSは正規表現評価のみで一部ルール未適用、という警告があり、包括的なアクセシビリティ合格ではない。`qa/detect.txt` に記録。
