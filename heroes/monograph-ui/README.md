# ミニ社長 × TELEMO — MONO graph参照のヒーローUI10案

参照：https://www.tombow.com/sp/monograph10th/

参照先の公開OG画像とHTML/CSSから、製品を斜めに大きく見せる構図、板状の面を重ねた奥行き、白い余白を読み取った。サイト全体の動きを実ブラウザで測定したものではない。

今回はミニ社長とTELEMOの文字を主役にした追加案。前の10案は `../generated-ui/` に保持。元のLPは変更していない。

## 素材

- 背景・文字造形：組み込みimage_genで10点を別々に生成。既存TELEMO立体ワードマークをブランド参照に使用。
- ミニ社長：既存 `assets/concierge/president-cutout/poster.webp` をHTMLで重ねる。人物の描き直し・ポーズ変更なし。
- 社長の固定位置：PC右24px・下16px、SP右14px・下12px。PCは160×240px、SPは90×135px。
- コピー・CTA：現行LPのヒーロー文言とリンクを使用。
- 参照サイトの写真・ロゴ・製品・周年表記・数値は取り込んでいない。
- パレット：白・ティール・濃紺・オレンジ。素材の陰影による濃淡あり。
- プロンプトと元画像パス：`prompts.json`。

## 閲覧

`index.html` で比較。各案の「案を開く」から実際のUIを表示できる。生成した文字の造形はイメージであり、新しいロゴの確定案ではない。

## 確認結果

全10案をPC1280×800・SP390×844で撮影し、計20画面を目視。各案のTELEMO表記、コピーと画像の重なり、ボタン、固定社長の表示を確認した。横はみ出し、画像欠落、見出し・主CTAの画面外配置は0件。社長の固定位置は同一幅で全案一致。記録は `qa/layout.json`。

`npx impeccable detect heroes/monograph-ui/` は終了コード0・指摘0。単独CSSは正規表現のみの評価で一部ルールが未適用、という警告あり。ログは `qa/detect.txt`。
