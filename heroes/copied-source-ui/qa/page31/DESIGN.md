# 15〜29案の設計・検証メモ

対象はフルLPではなく、既存の比較HTMLへ追加する15個のヒーローUI。制作対象のサービスはTELEMO、利用者は営業電話を任せる手段を探している企業担当者。次の行動は既存LPの音声デモを聴くこと。参照元の構図を変えながら、同じ文言と行動を比べられるようにする。

## 事実・素材の棚卸し

TELEMOという名称、営業電話をかけるAI、商品説明から意向確認まで対応する説明、既存LPの通話サンプル、音声セクションのID、相談セクションのID、ミニ社長の既存切り抜き、白・紺・ティール・オレンジ、既存の紙・電話を題材にした生成素材、HTMLで編集できるコピー。

## 伝えることと根拠

- 営業電話をTELEMOに任せられる → ヒーローの見出しと商品説明・意向確認の補足。
- 会話の実物を確認できる → 既存LPの音声サンプルへ進むリンク。
- 導入の相談ができる → 既存LPの問い合わせ欄へ進むリンク。

新しい実績、価格、顧客、成果数値は追加していない。すべての見出しは「営業電話は、TELEMOがかけます。」、補足は「商品説明から意向確認まで、AIが電話で対応します。」に揃えた。主ボタンは「音声デモを聴く」、副リンクは「導入を相談する」。

## 構図と実装

指定されたWebDesignClip31ページ目に掲載された構図を基準にしている。独自の方向を抽選する工程は使わず、taste-skillの単一セクション向け手順に従って、既存ブランドの色・書体・CTAを維持した。

「TELEMOの電話・書類・ミニ社長を、各参照サイトの主役・写真窓・文字組みへ置き換える」を共通の発想にした。15件の対応と採用理由は `../../page31-specs.json` の `take` に保存している。

新しい生成背景は6点。workspace、chalk、phone-loop、headset-dark、pixel-office、phone-splash。組み込みimage_genでそれぞれ生成し、`../../assets/page31/` に保存。プロンプトと生成元は `../../page31-image-manifest.json`。既存の05-dars、03-pilot、07-esneaker、09-yukimi、10-brother、13-mamoroomの生成背景も使用している。生成画像の再加工は行わず、HTML/CSSの窓とトリミングで組み込んだ。

文字とボタンは画像ではなくHTML。画像がなくてもサービス名・説明・CTAが読める。15案を前後に切り替えるリンク、一覧に戻るリンク、元LPへのロゴリンクを用意した。原本LPのルート直下HTML/CSS/JSには変更していない。

## 適用範囲と例外

ヒーロー比較という依頼範囲を守り、フルページ向けの「4枚以上の写真」「8要素以上の動き」は追加していない。taste-skillの検査では `few-pictures` / `still-page` をこの範囲の例外として明記。動画や大きな登場アニメーションは加えていない。主CTAは実際の音声デモへ遷移する。

クーピー案の幾何形状、ユビー案の円、多摩美術大学案のクリップ、ぽたぽた焼案の人物の丸枠は、ユーザー指定の掲載サイトの構図を比較するために採用。ロゴ、実績数値、周年表記を作り出す用途には使っていない。クリップボードの枠や太い円は構図の一部で、UIカードの装飾として反復していない。

最終taste-skill検査は15案とも1440・768・390pxでFAIL 0。明示した範囲の例外は `few-pictures` / `still-page`。結果は `taste-summary.json` と各 `taste-*/report.json`。全案の最終スクリーンショットは幅ごとにコンタクトシート化して目視確認した。ソースlintは16ファイルでFAIL 0、WARN 0。

残ったWARNの判断：

- `no-footage`：静的ヒーローの構図を比較する依頼のため動画は追加しない。
- `name-only-title`：検査器は日本語文を単語数だけで名称と判定している。見出し自体が「営業電話は、TELEMOがかけます。」で役割を説明し、直下にもAIの対応内容があるため維持。
- `small-title`：768pxの27〜30px見出しはPCより小さいが、固定文言を2行で読み切れる寸法として採用。スマートフォンと同じ書体・余白で一貫している。
- `hero-void`（多摩美術大学・ユビー・ぽたぽた焼）：中央のクリップボードや円形の人物枠を囲む空間は参照構図の要点。別の要素で埋めず維持。
- `off-centre`（FABRIC）：左の文字面と右の写真面を分け、写真を端まで並べる掲載画面の構図を維持。本文やCTAの実際の切れはない。
