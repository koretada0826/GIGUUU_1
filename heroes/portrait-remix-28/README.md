# 28案の組み合わせ版

28番の丸い人物枠・縦書きコピーを基準に、19番の電話コードの曲線と16番の紙の質感を組み合わせた独立HTML。

表示：<http://127.0.0.1:4173/heroes/portrait-remix-28/>

- `index.html`：本文、ミニ社長、文字、CTA。既存LPの音声デモと相談欄へ移動する。
- `style.css`：白・紺・ティール・オレンジの既存ブランド色、丸枠と縦書き、画面幅・高さに応じた配置。
- `assets/background-desktop.png`：PC用の横長背景。
- `assets/background-mobile.png`：タブレット・スマートフォン用の縦長背景。
- `prompts.json` / `image-manifest.json`：背景2点の最終プロンプト、組み込みimage_genでの生成元と保存先。
- `qa/`：表示検証、スクリーンショット、既存ファイルのハッシュ。

背景は電話・コード・白い紙・紺のノート・小さなオレンジのクリップを周辺に配置し、中央を空けた生成イメージ。文字、ミニ社長、丸枠、ボタンは画像に焼き込まず、HTML/CSSで構成。ミニ社長は既存の `../../assets/concierge/president-cutout/poster.webp` を使用した。

この案は `heroes/copied-source-ui/` の29案と別のフォルダに作成。元の28案、比較一覧、共通CSS、LP本体の内容は変更していない。

## 設計の前提

営業電話をAIに任せたい企業担当者が、まず音声デモを聴くためのヒーロー。TELEMOという名称、営業電話、商品説明、意向確認、既存の音声デモ、導入相談、ミニ社長、ブランド色、紙に蓄えた営業現場の知見を材料にした。

既存28案の見出し・説明・CTAを使用。新しい実績・数値・顧客・価格は追加していない。主張は「AIが営業電話をかける」で、確認する行動は既存の会話サンプルへのリンク。

考え方：28案の人物を囲む円を、周囲の電話コードと紙による一枚の紙面へつなげる。既存セクションを組み合わせるため、taste-skillの単一セクション向け手順を使用し、方向の抽選は行っていない。

## 表示確認

1440×1000、1440×900、1280×900、768×1024、390×844、360×800で撮影し、画像と文字の欠落、横はみ出し、文字・ボタンの切れ、人物枠との重なり、404、JavaScript/Consoleエラー、意図しない外部通信を検査。主ボタンは各画面の最初の表示範囲に配置。音声デモ・相談欄への実際のリンクも確認。

原本28案と全29案、共通CSS、ルートのindex.htmlは保存したハッシュと比較。`qa/baseline.json` の対象は変更なし。

anti-slopのスキャンとソースlintは指摘0。taste-skillの確認は1440・768・390px。独立したヒーロー案なので、フルLP用の画像4枚以上・8要素以上のモーションは追加せず、`few-pictures` / `still-page` を適用範囲の例外として記録している。動画・フォーム送信機能は今回の制作範囲に含まれない。
